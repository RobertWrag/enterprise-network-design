# Enterprise Network Design

## Project Overview

This project focuses on designing and documenting a simulated enterprise network infrastructure for Adriatic Tech Solutions d.o.o., a fictional company operating across two locations: Zagreb and Split.

The goal is to design a secure, scalable, and logically segmented network that supports corporate departments, internal services, voice communication, guest access, and remote connectivity.

## Company Environment

- **Headquarters:** Zagreb – 200 employees
- **Branch Office:** Split – 50 employees
- **Network model:** Two interconnected sites with hybrid and remote workers
- **Simulation platform:** Cisco Packet Tracer

## Project Objectives

- Design an enterprise network topology.
- Implement VLAN-based network segmentation.
- Develop an IPv4 addressing and subnetting plan.
- Plan routing and inter-site connectivity.
- Separate corporate, server, DMZ, voice, management, and guest networks.
- Define basic network security controls.
- Test and document network connectivity.

## Technologies and Tools

- Cisco Packet Tracer
- diagrams.net
- Git and GitHub
- IPv4, VLANs, routing, ACLs, VPN concepts

## Project Status

**Status:** Planning and design

The project is being developed in stages, starting with network requirements and documentation, followed by topology design, simulation, configuration, and testing.

## Disclaimer

This is an independent educational project using a fictional company and simulated infrastructure. It does not represent a production network or actual customer environment.
